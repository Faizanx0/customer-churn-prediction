# Customer Churn Prediction

An end-to-end machine learning project to explore customer churn and build a model that predicts whether a customer may leave a telecom service.

## Project goals

- Explore customer data using Pandas.
- Clean and validate data.
- Analyze patterns associated with customer churn.
- Build and evaluate machine learning models.
- Document findings and limitations.

## Tech stack

- Python
- Pandas
- NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Project status

Currently in development — data cleaning and exploratory data analysis.

## Dataset

This project uses the Telco Customer Churn dataset. Follow the dataset source's terms and licensing requirements when obtaining or sharing the data.

Place the downloaded CSV in the local `data/` directory. The raw dataset is not included in this repository by default.
